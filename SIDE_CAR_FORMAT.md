# SIDE_CAR_FORMAT.md

## Purpose

Track local edit history without modifying the PDF format.

## Format
JSON

## Example
```json
{
  "version": 1,
  "history": [
    {
      "timestamp": "2026-01-27T10:32:00Z",
      "summary": "Edited text on page 2",
      "snapshot": "snap_001"
    }
  ]
}
```
