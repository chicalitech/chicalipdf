## chicalipdf

chicalipdf is a fast, offline-first PDF viewer and editor for Windows.

No subscriptions. No accounts. No cloud. Just open a PDF, edit it, sign it, and move on.

### Why chicalipdf

Most PDF tools are either:
- web apps that force uploads and subscriptions, or
- bloated desktop software with overwhelming UI

chicalipdf is designed to feel like a built-in operating system utility:
quiet, fast, and dependable.

### Features (v1)
- View PDFs locally
- Fill forms
- Edit existing text (good-enough edits)
- Add signatures
- Local version history (no more FINAL_FINAL.pdf)

### Explicit non-features
- No OCR
- No cloud sync
- No collaboration
- No AI
- No telemetry
